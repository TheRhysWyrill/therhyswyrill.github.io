{% comment %} Body of a genre landing page. The page stubs in genres/ are generated by generate_genre_pages.py and carry nothing but the genre name — everything below is computed at build time, so a page can never drift from the archive. This is deliberately a *front door*, not a second archive. The full list of reviews lives here as a chip list and the grid lives on /reviews/?genre=X, which already sorts, searches and paginates. What's added here is the editorial part: which three to start with, and which ones TRW did not give a clean yes to. Genre matching is an exact comparison against each comma-separated segment of the review's `genre` field, not a substring test — "Horror" must not swallow the 12 "Survival Horror" reviews.
